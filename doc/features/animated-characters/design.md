# 角色模型接入设计

状态：已实现，通过本地验证。依据：[需求](prd.md)。

## 资产与边界

采用 KayKit Adventurers 的固定提交 `672074b73ba276876a19e8816ecdc5241817ab47`。选择 Knight 和 Barbarian，保留各自原骨骼与必要动作，不改变战斗规则。角色外观不同作为首版阵营识别，HUD 保留青绿／锈红。原仓库 README 标注 75 个动作，实际两个 GLB 均包含 76 个动画条目，以文件检查为准。

本地准备脚本从原始 GLB 选择 12 个必要动作，重排引用与二进制数据，不改变网格、贴图或动作关键帧；附原许可、固定来源及哈希。运行时移除未装备的副手／双手武器和多余盾牌，以待机包围盒归一化高度。顶层 root 的水平位移轨道固定到起点，保留垂直移动和身体骨骼动作，避免与场景走位叠加。

## 表现所有权

`Combat` 不修改。`CharacterVisual` 负责加载结果、骨骼剪辑取样、材质闪光和自身资源释放；不产生伤害、扣费或回合转换。Arena 保留原角色作为加载／失败降级，成功后仅隐藏其几何表现，新的模型挂在原站位根节点，沿用同一角色层和阴影。

角色姿态由快照中的行动、行动进度和结果反馈决定，不按新入队输入重播。普通攻击将素材中的接触段对齐 0.55 秒，收势在 0.79 秒结束；反击立即显示接触姿态再完成余势，敌方前摇和反击窗口保持预备姿态，敌人伤害边界仍为结算末端。动画只解释既有事件，不能用动画完成事件驱动结算。快斩从原素材 45% 的准备段开始，绕过循环边界后在约 6.7% 的接触段命中，再完成收势；重斩取约 55% 的接触段。不是把所有素材的中点当作命中点。敌方前摇／窗口／结算沿同一取样方向衔接；被反击取消后不会在回合结束时补播敌方挥砍或突进。

Arena 的表现走位沿双方连线推进／回归，补足素材武器与目标之间的距离；不改变规则目标或时间。受击／格挡成功播放结果动作，伤害粒子与金属火花保持原规则边界。终局使用表现时钟播放倒地／庆祝；暂停不推进，重开清零。模型加载完若战斗正在进行，从当前快照取样，不补播过期事件。

## 异步与资源

两模型独立加载，状态分别为加载中／就绪／失败。新模型头盔较大，过肩机位向侧后方让出空间，焦点跟随来袭对手，修正量用 0.18 秒过渡，避免在动作切换时跳变；降低动态效果仍使用稳定机位。界面用简短状态提示；失败保留原型几何，不报整场 WebGL 失效。销毁后才返回的模型必须立即释放，不加入场景；重开复用已加载资源。资源路径使用 `import.meta.env.BASE_URL`。

角色几何、材质、贴图与骨骼纹理由模型适配器释放；原场景资源继续由 Arena 释放，避免重复拥有。选择的原始两模型共约 7.3 MB，准备后以实际体积记录；两角色原始全部配件各约 7 千三角形，运行时隐藏／移除多余配件后再测绘制调用、纹理和三角形。桌面和 390×844 竖屏作为本轮取证条件，不承诺实体手机帧率。
