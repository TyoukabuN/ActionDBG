# 免费低多边形角色与骨骼动作

日期：2026-10-15。状态：已实现，通过本地验证。上游：[项目目的](../../project-purpose.md)、[连续出牌需求](../cinematic-qte/prd.md)。

用户选择卡通低多边形、优先自带骨骼与战斗动作的免费套装。目标是将现有几何拼装角色替换为可辨识的骑士／蛮族，并让出牌对应真实骨骼动作。

- AC-01：己方骑士用剑盾，敌方蛮族用斧盾；均为随游戏发布的免费 CC0 资源，有原始许可与来源记录。资产使用仓库 Pages 基础路径，不依赖远端运行时服务。
- AC-02：待机、快斩、重斩、格挡、敌人前摇／攻击、反击、受击、胜负有对应骨骼表现；不同时显示互斥武器，不停留在 T 姿势。原始动作允许按现有时长重映射，不能改 AP、伤害、0.55 秒生效／0.79 秒行动完成或反击的即时生效。
- AC-03：连续出牌仍按队列执行，后续输入不重置当前动作；暂停冻结骨骼和表现，重开清空受击／终局状态。横屏与手机竖屏可见双方，黑边仍在角色后、粒子在前。
- AC-04：模型加载期间提供状态提示；失败明确提示并保留程序化角色继续游戏。异步加载在场景销毁后不得重新挂载，所有模型资源可释放。

不增加卡牌、敌人规则、生成服务、角色编辑器、音频、外部模型平台账号或通用动画重定向系统。本版选同一套资源中的原生动作，不另外拼接 Mixamo 骨骼。
