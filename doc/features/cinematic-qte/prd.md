# 演出式战斗与按钮 QTE

状态：已就绪。来源：用户对固定战斗镜头的纠正；[首个战斗原型](../../prd/first-combat-prototype.md)。

玩家观看持续展开的攻防演出，在慢动作窗口按下招式按钮改变演出与结果。目标仍为击败剑士，时间、行动点、冷却和保留反击资源形成取舍；伤害和格挡反馈帮助玩家理解结果，结束后立即重试。

- FR-01：默认使用屏幕招式按钮与数字键 1–4；按一次直接出牌，无需再提交。原有队列模式作为可切换的对照，模式只能在开始前或胜负后切换。
- FR-02：普通窗口内可接续不同招式。动作播放不消耗剩余决策时间；返回决策后继续倒计时，不重置为四秒。同张牌每轮最多使用一次。资源不足或无合法招式时进入反击/结算。继续按钮或 Space 主动结束普通窗口。
- FR-03：反击窗口按 Counter 直接触发反击；过期或跳过照常结算。沿用生命、费用、伤害、冷却、每轮一次反击和致死取消。
- FR-04：全景建立空间关系，敌人起手、轻/重击、格挡、反击、受击和结束采用不同分镜。机位切换由实际动作/事件驱动，保持同一侧空间方向。决策窗口避免持续旋转，UI 保持清晰。
- FR-05：暂停冻结时间与摄像机，重试清空镜头残留。降低动态效果偏好使用稳定全景，无强制移动或抖动。

验收：AC-01 屏幕按钮与键盘均能立即出牌并切换动作分镜；AC-02 连招、剩余时间、资源、重复/非法输入正确；AC-03 反击、过期、胜负与五次重试成立；AC-04 多个实际分镜可见，决策可读、无空白画面或浏览器错误；AC-05 暂停/恢复、降低动态效果、队列对照模式可用。

本轮不增加手柄、移动端专用操作、自由移动、抽牌、音频、正式角色模型、完美时机奖励或随机 QTE 按键。当前 QTE 是限时招式选择，后续再通过试玩决定节奏与评级。


## 2026-10-14 回合制纠正（当前需求）

以下需求替代 FR-02–03 中“敌方起手后先让玩家普通应对”的含义。此前记录保留为历史。

- FR-06：明确玩家／敌人独立回合。玩家先手，在自己回合按按钮或数字键使用普通牌，4 秒剩余选牌时间内可接续不同牌；演出暂停选牌计时。结束回合、超时或没有合法普通牌时交出行动权。
- FR-07：敌人每回合打一张牌，右上角立即展示；伤害牌只在玩家有当前可用反击牌时进入 2 秒反击窗口，否则直接结算。敌人回合不出现 Response 或普通选牌。非伤害牌不触发反击。
- FR-08：双方独立持有 AP，初始／上限为 3；仅在自己的回合结束补满。反击使用玩家资源，其消耗持续到下次玩家回合结束。任何单卡、反击阶段或切换到回合开始都不额外恢复。
- FR-09：冷却按持有者的回合计数，每张牌在同一计数回合只用一次；1 回合冷却牌跳过下个玩家回合。格挡减伤 2，跨回合保留到下次实际受击；反击取消不消耗格挡。
- FR-10：中文 HUD 显示行动方、双方 AP、敌方已提交牌与合法操作。保留右肩／行动分镜、反击黑边、粒子、触屏竖屏、键盘、队列对照、焦点暂停与快速重开。

验收：AC-06 完成玩家出牌→自己回合恢复→敌人出牌→反击／直接结算→仅敌方恢复的循环；AC-07 缺手牌／费用／冷却和非伤害牌正确跳过反击，敌人回合从不进入普通选牌；AC-08 反击消耗可在下一玩家回合观察到，格挡跨回合、胜负取消、暂停与重开正确；AC-09 中文桌面及竖屏实际输入可完成这一循环，无页面错误或横向溢出。

不增加默认敌方新卡牌、抽牌／弃牌、敌方反击、递归阶段链或正式美术。此前范围外的“移动端专用操作”已由中文竖屏迭代实现，不再限制现有触屏支持。
