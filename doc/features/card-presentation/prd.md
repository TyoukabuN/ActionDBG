# 正式牌面：需求

状态：可实现；流程：标准；更新：2026-10-15。

## 目标与范围

将四个招式按钮做成有完整信息层次的游戏卡牌，参考《杀戮尖塔》的费用、标题、插画与效果区层级。玩家仍以点击或数字键出牌，消耗行动点，在时间压力下选择招式，通过演出和结算反馈确认结果，胜败后可重试。

- FR-001：四张卡牌分别展示费用、中文牌名、独立插画、类型、完整效果和可用状态；费用与实际卡牌定义一致。
- FR-002：可用、不可用、已入队和演出中有文字和视觉反馈；键盘焦点可见；效果文字不依赖悬停。
- FR-003：桌面同时展示四张牌；手机竖屏以可横滑手牌展示完整牌面，结束回合按钮留在手牌外。点击一次仍直接出牌，键盘快捷键保持。
- FR-004：插画本地加载，兼容仓库托管路径；加载失败时保留招式符号、效果文字和正常操作。

不增加牌库、稀有度、抽弃牌、拖拽选目标或新规则，不改变行动队列、冷却、费用、伤害、决策时间和镜头逻辑。原创插画与项目骑士题材呼应，不使用参考游戏的原画、标志或卡框资源。

## 验收

- AC-001：1280×800、1440×900 牌面完整，四张费用、标题、效果与状态可读，无文字截断或页面横向溢出。
- AC-002：390×844、320×740 可横滑到第四张牌，效果与状态完整，按钮触摸区域不少于 44 像素，结束回合可达；横屏 844×390 无页面横向溢出，可纵向滚动游玩。
- AC-003：鼠标、手机点击和数字键仍触发现有出牌行为；演出时继续入队、反击窗口和旧序列模式状态正确；图片失败不阻断出牌。
- AC-004：类型检查、现有单元测试、生产构建通过，生产预览插画请求成功，无新增浏览器错误。
